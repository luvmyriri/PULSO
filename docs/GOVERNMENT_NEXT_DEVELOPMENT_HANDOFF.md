## Suggested next implementation slice

Start with the remaining report/work-order commands and notification delivery. A reviewable slice should demonstrate: one durable civic event per accepted command; unchanged state on denial or failed validation; 409 plus current version on stale input; one outcome for an identical retry; no duplicate notification after worker restart; and an accessible refresh/review path in the government UI. Run these checks on PostgreSQL as well as the existing focused suite. Keep each command small enough to trace from API through record, timeline, audit, outbox, resident projection, and UI feedback.

Then complete the authorization and evidence/records gates for the bounded pilot. Project, procurement, OBO, finance, emergency, and predictive expansion depend on the decisions above. A critical priority label alone does not authorize emergency handling. A heuristic score alone does not justify a maintenance decision.
