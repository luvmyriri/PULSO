# PULSO

PULSO is a City Engineering Department Management System with connected resident reporting and government operations experiences. See [PRODUCT.md](PRODUCT.md) for approved product commitments and [SETUP_GUIDE.md](SETUP_GUIDE.md) for local setup.

## Caloocan jurisdiction reference

The PostGIS city-boundary reference is the Caloocan City feature from [geoBoundaries gbOpen Philippines ADM3](https://www.geoboundaries.org/api/current/gbOpen/PHL/ADM3/), which credits **NAMRIA, PSA, and OCHA Philippines**. The dataset metadata states **Creative Commons Attribution 3.0 Intergovernmental Organisations (CC BY 3.0 IGO)**. See [reference-data.md](docs/reference-data.md) for the retrieval date, exact source URL, file checksums, and limitations.

This is a planning reference, not an LGU-certified legal boundary. Some existing visual map overlays still use a separate legacy GeoJSON source; the geoBoundaries credit in map views identifies the server-side jurisdiction reference, not those overlays or Google basemap imagery.
