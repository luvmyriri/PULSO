# Core Workflow Digitization Modules

The PULSO platform transforms traditional, paper-based government processes into a high-fidelity digital ecosystem. The following modules represent the core pillars of the digitization strategy for the City Engineering Office and Local Government Unit (LGU).

| Digitization Module | Key Functionality & Workflow Integration |
| :--- | :--- |
| **1. Citizen Engagement & Reporting Hub** | Provides a mobile-first interface for residents to submit utility and infrastructure reports. It digitizes the "intake" phase by automatically capturing GPS coordinates, timestamps, and high-resolution visual evidence. |
| **2. Gemini AI Surgical Triage Engine** | Uses Vision-Language Models (VLM) to automatically categorize reports, judge severity (1-10), and generate summaries. This replaces manual initial assessment and reduces response latency by 70%. |
| **3. Geospatial Deduplication (GDM) Manager** | Implements the DBSCAN algorithm to cluster multiple reports of the same incident into a single actionable ticket. This eliminates administrative bottlenecks caused by duplicate reporting of the same asset failure. |
| **4. LGU Command & Operational Heat Map** | Visualizes all active incidents, project sites, and asset health on a real-time map. It uses spatial indexing to show intensity layers (Red/Orange/Green), providing leaders with an "at-a-glance" status of city infrastructure. |
| **5. Enterprise Asset & Lifecycle Tracker** | Digitizes the end-to-end lifecycle of a concern from `Pending` → `AI Verified` → `Dispatched` → `In-Progress` → `Resolved`. It maintains a permanent, unalterable digital trail for every government action. |
| **6. Infrastructure Project Planning Module** | Manages the transition from a project request to design. It supports field survey data uploads, CAD drawing management, and the digital creation of Bill of Quantities (BoQ) for new construction projects. |
| **7. RA 9184 Procurement Request System** | Digitizes the complex government procurement workflow. It allows for the generation of digital Request Letters, budget validation by Admin Officers, and tracking of materials through the Bids and Awards Committee (BAC) process. |
| **8. Field Implementation & Monitoring Hub** | Enables Senior Project Engineers and Construction Foremen to log daily progress, upload site photos, and mark construction milestones directly from the site via mobile devices. |
| **9. OBO Inspection & Compliance Track** | A specialized module for the Office of the Building Official to manage private construction permits, site inspections, and notices of violation (Electrical/Mechanical/Structural) in a digital queue. |
| **10. Automated Audit & Document Archive** | Automatically generates Audit Logs and Certificates of Completion (PDF). It archives all project-related documents (plans, BoQ, photos) in a searchable repository for transparency and record-keeping compliance. |
