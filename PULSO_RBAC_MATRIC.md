# PULSO Role-Based Digitization Matrix

This matrix maps the official plantilla positions of the City Engineering Office to their digitized roles and key permissions within the PULSO system.

| Confirmed Plantilla Position | PULSO Digitized Permissions |
| :--- | :--- |
| **City Engineer (Dept. Head II)** | Final executive sign-off on work orders, procurement approvals, and global system dashboard access. |
| **Asst. City Engineer** | Drafts and issues Certificates of Completion; manages division queues and takes action on escalated tickets. |
| **Administrative Officer V** | Budget verification and procurement request routing; authorizes user accounts and manages administrative logs. |
| **Admin Clerk / Encoder** | Primary data intake officer; digitizes physical documents and encodes initial report details. |
| **Records Officer** | Digital archive management; retrieves historical permits and maintenance records for audit reports. |
| **Division Chief (Planning)** | Task allocation for design-phase project tickets; reviews BoQ (Bill of Quantities) submissions. |
| **Architect / Civil Engineer** | Creation and upload of technical design plans (PDF/DWG) and structural calculations. |
| **Engineer II (Estimator)** | Digital generation of itemized Bill of Quantities (BoQ) linked directly to project tickets. |
| **CAD Operator / Draftsman** | Uploads AutoCAD drawings and technical appendices to the centralized project record. |
| **Project Engineer (Field)** | Real-time site progress logging, photo evidence uploads, and procurement request generation from the field. |
| **Construction Foreman** | Daily task completion tracking and labor activity logging for direct-hire LGU repairs. |
| **Building / Electrical Inspector** | Digitized site inspection visit reports, milestone pass/fail flags, and OBO violation recording. |
| **Verified Resident / Citizen** | End-user portal for report submission, GPS-tagged issue creation, and real-time status tracking via push alerts. |
